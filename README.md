# Harvest resource pack

Pixel-art menu backgrounds, banners and button icons for the
[Harvest](https://github.com/JawshTheDark/harvesteco) plugin suite for
[Pumpkin](https://github.com/Pumpkin-MC/Pumpkin) (HarvestEco, HarvestShops, HarvestEdit, HarvestLog).

All art is generated by `generate.py` (needs Pillow), so it can be re-themed and rebuilt:

```
pip install pillow
python generate.py
```

That writes `harvest_pack/`, `harvest-pack.zip` and `harvest-pack.sha1`.

## Use it on a server

In `pumpkin.toml`:

```toml
[resource_pack.java]
enabled = true
url = "https://github.com/JawshTheDark/harvest-pack/releases/download/v1.0.0/harvest-pack.zip"
sha1 = "<contents of harvest-pack.sha1>"
prompt_message = "Harvest menus"
force = false
```

Players who decline the pack still get working menus, with plain vanilla items and a blank
frame in place of the art.

## How it works

Chest menus put a font glyph in the window title: one character moves the cursor left, one is the
whole 176x222 background, one moves it back, and the real title follows on top. Button icons are
items with an `item_model` of `harvest:icon/<name>`. Dialog banners use the `harvest:banner` font.
